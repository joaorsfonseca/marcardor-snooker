# Marcador de Snooker

Placard de snooker para dois jogadores, numa única página HTML estática (sem dependências nem build).

**Online:** https://joaorsfonseca.github.io/marcardor-snooker/

## Funcionalidades
- 15 vermelhas + 6 cores com a sequência oficial (vermelha → cor; depois amarela → preta).
- Pontos em jogo, diferença, máximo possível por jogador e alerta de snookers necessários.
- Faltas (4–7 pontos, vermelhas perdidas, adversário joga ou infrator repete, bola livre).
- Preta recolocada em caso de empate, encontro à melhor de N frames, melhor tacada.
- Desfazer ilimitado e estado guardado no `localStorage` do browser.

## Executar localmente
Abrir `index.html` no browser.
